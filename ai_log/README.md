# AI session logs

This directory contains the verbatim user-visible messages available to the assistant from the current conversation when this archive was updated. It does **not** claim to be a complete export of all AI sessions, hidden reasoning, IDE-agent sessions, or tool transcripts: those records are not accessible for export here.

To meet a requirement for the _complete, unedited_ history, export the original conversations and any IDE/agent logs from each tool and add the raw exports to this directory without rewriting, truncating, or sanitizing them. Keep the original exports alongside this disclosure.
